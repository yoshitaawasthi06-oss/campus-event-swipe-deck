# Campus Event Swipe Deck

Swipe-to-RSVP for campus events instead of a boring list.

## Features
- Event directory loaded from a local list (`events.js`): title, category, date, location
- Swipe right = "I'm in", swipe left = "skip" (drag the card, use the ✓ / ✕ buttons, or the arrow keys)
- Category filter (All, Tech, Cultural, Sports, Music, Academic)
- Bonus: Undo last swipe (↶ button or Backspace)
- Bonus: Countdown badge on RSVP'd events
- RSVPs are saved in the browser's localStorage, so they persist after closing and reopening the app

## Run it
Open the live link, or download the files and open `index.html` in a browser.

## Tech
Plain HTML, CSS and JavaScript. No frameworks, no login, no server.
